PricempirePlus

Privacy Policy

Last updated: May 23, 2026

PricempirePlus is a Chrome extension that enhances selected Pricempire item pages and provides a user-initiated context-menu search shortcut. This policy describes the extension's data handling.

Information We Collect

PricempirePlus does not collect, sell, transmit, or store personal information, browsing history, analytics, or the content of visited pages on any server operated by the publisher.

Stored Preference

The extension stores one setting, whether the optional "Move Market Offers to Bottom" feature is enabled. This preference is saved using Chrome's synchronized extension storage so it may be available across the user's signed-in Chrome browsers. The publisher does not receive or access this setting.

Access to Pricempire Pages

On Pricempire CS2 item pages, the extension may read the rendered page structure to locate the Market Offers and Similar Items sections. When enabled by the user, it changes their position on the page. This page access is used only for the requested layout adjustment and is not used to collect or transmit data.

Context-Menu Search

When a user selects text and explicitly chooses the extension's search action, the extension opens a Pricempire search URL containing the selected text as a search query. That navigation sends the query to Pricempire in the same way as performing a search on its website.

Third-Party Services

Use of the Pricempire website is governed by Pricempire's own privacy practices. PricempirePlus is not affiliated with, endorsed by, or operated by Pricempire.

Changes

This policy may be updated when the extension's functionality or data handling changes. The latest version will remain available at this URL.

Contact

Questions about this policy can be submitted through the PricempirePlus GitHub repository.
